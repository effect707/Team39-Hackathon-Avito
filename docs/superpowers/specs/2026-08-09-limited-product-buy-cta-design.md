# CTA для лимитированного товара без заявки

## Цель

Когда пользователь открывает лимитированный товар и у него нет активной заявки, основная кнопка должна называться «Купить». Это отражает единый пользовательский сценарий: backend при нажатии либо сразу выдаёт право, либо ставит пользователя в FIFO-очередь.

## Границы

- Меняется только результат `getQueueCta(null, true)` с «В очередь» на «Купить».
- Состояния `WAITING`, `GRANTED`, `CHECKOUT_PENDING`, `SOLD_OUT`, `PURCHASED` не меняются.
- Терминальные состояния, для которых повторный вход допустим (`EXPIRED`, `PAYMENT_FAILED`, `CANCELLED`), сохраняют действие «В очередь».
- Обработчик клика, API и серверная логика очереди не меняются.

## Проверка

Регрессионный unit-тест проверяет начальное действие лимитированного товара и сохраняет проверки активных/терминальных состояний. Затем запускаются frontend-тесты и ESLint.
